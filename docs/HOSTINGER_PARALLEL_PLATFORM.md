# Hostinger Parallel Platform: aievolutionaryevolutions.com

## Role
aievolutionaryevolutions.com is the web-facing parallel platform for the Linux RPG Educational System.

## Core surfaces
1. Linux RPG Academy
2. Bedrock Multiverse Lab
3. OMARCHY Workshop
4. AI Jarvis Command Center
5. AI Building AI Laboratory
6. Programming Forge
7. GitHub Foundry
8. Blockchain Lab
9. Robotics/Humanoid Academy
10. MemPalace Knowledge Library
11. Proof & Transparency Vault
12. Product Creation Studio

## Shared canonical model
User -> Character -> Skill Tree -> Quest -> Mission -> Artifact -> Test -> Proof -> XP -> Achievement -> Product

## Cross-device behavior
The site must use responsive layouts and cloud-backed state so the same account can continue on iPhone, iPad, or laptop.

Phone/tablet mode emphasizes:
- quest cards
- lesson reading
- approvals
- progress
- status
- chat/Jarvis interaction

Laptop mode adds:
- code views
- terminal-oriented instructions
- GitHub workflows
- detailed diagnostics
- proof artifacts

## Integration boundary
The Hostinger site is the interface and learning surface.
Bedrock + OMARCHY remains the Linux execution environment.
GitHub remains the durable engineering source of truth.
ChatGPT/Jarvis remains the conversational control layer.

## Acceptance checks
- Mobile-first navigation works on iPhone and iPad.
- Desktop layout supports ASUS laptop workflows.
- Quest IDs and artifact IDs match GitHub records.
- No secrets are stored in browser code or repository files.
- Execution actions requiring Linux are handed off to the Bedrock/OMARCHY workstation.
